Compatibility and release status

The same AES67 GStreamer-backed Python receiver runs on Windows, macOS and Linux when the matching system tools and network configuration are installed. This is currently a receive-only lab integration. Q-SYS hardware, PTP synchronization, full Super Admin role integration, and live passenger audio delivery require acceptance testing.
