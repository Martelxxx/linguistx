EXTENDED COVERAGE:
  An additional remote third-party IATA→ICAO PNG catalog is queried on demand.
  Supported codes depend on upstream catalog and assets, and a 2nd PNG source is tried.
  Images with insufficient resolution or unusable alpha crops are not displayed.
  Any missing asset leaves the airline name plus a quiet code identity, not an empty slot.

IMPORTANT DISTINCTION:
  A resolved flight number and an available authentic airline trademark are separate checks.
  Neither worldwide live-flight coverage nor every authentic airline mark is guaranteed.
  Actual flight matching requires supported Aviationstack API data and network access.
